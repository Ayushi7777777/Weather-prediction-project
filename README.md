# Weather App (Final Year Project)

## Overview
This project is a **Weather Prediction App** developed using Python.  
It fetches real-time weather data from an API and predicts future weather conditions.  
The app is designed to provide users with accurate and easy-to-read weather information.

---

## Features
- Fetches **current weather data** for any city.  
- Displays **temperature, humidity, wind speed, and weather conditions**.  
- Shows **7-day weather forecast** using prediction algorithms.  
- User-friendly interface built with **Streamlit / Tkinter / Web interface** (depending on your implementation).  

---

## Technology Stack
- **Python**: Core programming language  
- **Pandas & NumPy**: Data handling and processing  
- **Matplotlib & Seaborn**: Visualization of weather patterns  
- **Scikit-learn**: Machine Learning for prediction models  
- **Streamlit**: Web interface for user interaction  
- **OpenWeatherMap API** (or any public API): Fetch real-time weather data
